# Generated Bug-Audit Evidence

This directory is generated by:

```bash
.venv/bin/datadiff bug-audit --write-issues --overwrite-issues
.venv/bin/datadiff bug-hunt --cases 500 --seed 1
```

Files here are machine-generated evidence artifacts:

- `manifest.json`: portable audit manifest with environment, probe verdicts, expected/observed values, and candidate family keys.
- `bug-hunt-manifest.json`: portable end-to-end manifest linking the audit output, fresh fuzz run, report paths, and fresh-vs-known classification.
- `bug-hunt-manifest-fresh-candidates.json`: full generated case and normalized-output evidence for fresh candidates exported by the integrated hunt.
- `*.md`: issue draft generated directly from the manifest for each candidate family.

Some probes include deterministic sweeps in addition to the minimal trigger. The sweep summaries show how many related variants were checked and how many violated the same invariant.

The parent `new_issue/` directory contains reviewed issue records and final upstream-ready drafts. If a generated draft is manually edited for submission, copy or merge it into `new_issue/` root instead of editing this generated evidence in place.
